# Telegram бот + Mini App для объявлений (покупка/продажа/обмен)

Готовый проект на Python:
- Бот на `aiogram`.
- Mini App (внутри Telegram) на `FastAPI + HTML/CSS/JS`.
- Модерация с ролями (главный модератор и обычные модераторы).
- Профиль пользователя (аватар, количество объявлений, ссылки).
- Публикация в канал в нужном формате.

## Что уже реализовано

1. **Mini App с дизайном**
   - Тёмная аккуратная тема.
   - Форма подачи объявления.
   - Раздел профиля.
   - Разделы модерации (видны модераторам) и админ-панель (только chief).

2. **Система модерации и ролей**
   - `chief` (главный модератор):
     - видит заявки,
     - может одобрять/отклонять,
     - может редактировать уже опубликованные,
     - может удалять опубликованные,
     - может назначать/снимать модераторов.
   - `moderator`:
     - видит заявки,
     - может только одобрять/отклонять.
   - При отклонении указывается причина, пользователь получает её в личку.

3. **Профили**
   - Общее количество опубликованных объявлений.
   - Ссылки на объявления.
   - Аватар из Telegram-профиля (`getUserProfilePhotos`).

4. **Формат объявления**
   - Фото (обязательно для `sell` и `exchange`, для `buy` — не обязательно).
   - Название.
   - Описание.
   - Цена.
   - Кликабельный username автора.

5. **Выбор страны и валюты**
   - Россия → ₽
   - Казахстан → ₸
   - Беларусь → Br
   - Украина → ₴

6. **Cloudflare-ready**
   - Приложение запускается как обычный веб-сервис, удобно прокидывать через Cloudflare Tunnel.

## 1. Установка (очень подробно)

### Шаг 1. Установить Python 3.11+
Проверьте:

```bash
python3 --version
```

### Шаг 2. Скачать проект
Если уже в папке проекта — пропустите.

### Шаг 3. Создать виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### Шаг 4. Поставить зависимости

```bash
pip install -r requirements.txt
```

### Шаг 5. Создать `.env`

```bash
cp .env.example .env
```

Откройте `.env` и заполните:

```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
BOT_USERNAME=TheZontShopBot
APP_BASE_URL=https://ВАШ-ДОМЕН
CHIEF_MODERATOR_ID=6430400675
MODERATORS_CHAT_ID=-1003580269283
CHANNEL_CHAT_ID=-1003727981065
DATABASE_URL=sqlite+aiosqlite:///./data.db
```

## 2. Настройка Telegram

1. У бота в BotFather:
   - `/setdomain` → укажите ваш https домен mini app.
   - `/setmenubutton` → выбрать ваш бот → `Web App` → URL `https://ВАШ-ДОМЕН/webapp`.

2. Добавьте бота:
   - в чат модераторов (`-1003580269283`) с правом писать сообщения;
   - в канал публикаций (`-1003727981065`) как администратора с правом публикации/редактирования/удаления.

3. Запустите `/start` в личке боту.

---

## 3. Локальный запуск

```bash
python -m app.main
```

Откроется сервер на `http://0.0.0.0:8000`.

## 4. Публикация в интернет через Cloudflare Tunnel

### Установка cloudflared
См. официальную инструкцию Cloudflare (под вашу ОС).

### Быстрый запуск туннеля

```bash
cloudflared tunnel --url http://localhost:8000
```

Cloudflare даст URL вида:
`https://random-name.trycloudflare.com`

Его и впишите в `.env` как `APP_BASE_URL`.

После изменения `.env` перезапустите приложение.

## 5. Как пользоваться

1. Пользователь открывает мини-апп через кнопку в боте.
2. Заполняет форму.
3. Для `Продажа/Обмен` указывает `photo_file_id` (обязательно).
4. Заявка уходит в `pending` и сообщение в модераторский чат.
5. Модератор в mini app нажимает:
   - Одобрить → публикация в канал.
   - Отклонить → указывает причину, причина уходит пользователю.
6. Главный модератор дополнительно может:
   - назначать и снимать модераторов,
   - редактировать и удалять опубликованные объявления.

## 6. Структура проекта

- `app/main.py` — бот + API + бизнес-логика.
- `app/db.py` — база данных и модели.
- `app/auth.py` — проверка `initData` Telegram WebApp.
- `app/services.py` — сервисные функции.
- `app/templates/webapp.html` — интерфейс mini app.
- `app/static/styles.css` — стили.
- `app/static/app.js` — фронтенд-логика.
- `.env.example` — пример переменных окружения.
